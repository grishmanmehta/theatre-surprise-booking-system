# TheatreMagic – Private Theatre Surprise Booking Platform

TheatreMagic is a full-stack Flask-based web application that enables users to book private theatre screens for special occasions such as birthdays, anniversaries, proposals, and celebrations.

The platform provides an end-to-end booking experience including city and theatre selection, screen booking, media uploads, event customization, email confirmations, booking management, and an intelligent chatbot assistant for customer support.

## Key Features

* User Registration & Authentication
* Multi-City Theatre Selection
* Theatre & Screen Booking
* Time Slot Management
* Occasion-Based Event Planning
* Personal Message & Media Uploads
* Custom Decorations & Add-ons
* Email Confirmation System
* Admin Booking Dashboard
* Interactive Chatbot Assistant
* Responsive User Interface
